## 📌 About This Project

This repository contains my **Final AI & Machine Learning Project** completed as part of **Module 06 – Final AI & ML Project** of the Codomax Internship Program.

The project focuses on analyzing the Iris Flower Dataset and building a Machine Learning model to predict different Iris flower species.

---

## 🎯 Project Objectives

- **Understand the fundamentals of Artificial Intelligence and Machine Learning.**
- **Perform data analysis using Python.**
- **Explore and visualize the Iris dataset.**
- **Train Machine Learning classification models.**
- **Evaluate model performance.**
- **Make predictions using trained models.**

---

## 📚 Dataset Information

The project uses the **Iris Flower Dataset**.

The dataset contains three different flower species:

1. **Iris Setosa**
2. **Iris Versicolor**
3. **Iris Virginica**

### 🌸 Features Used

- **Sepal Length**
- **Sepal Width**
- **Petal Length**
- **Petal Width**
